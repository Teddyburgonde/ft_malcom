Objectif:

Créer un programme C qui fait une attaque ARP spoofing

-------------------------

Notions: 

ARP request: ✅️ 
C'est un message qu'on envoie sur le réseau pour dire 
"J'ai une ip, qui me dire: quelle est adresse MAC de cette adresse IP.

IP / MAC:  ✅️
Ip c'est adresse de l'ordinateur sur le réseau
Mac c'est adresse de la carte réseau de l'ordinateur
Pour communiquer il faut IP et le MAC du destinataire.

Le flow: ✅️

1. A envoie une ARP request: "Qui a l'IP de B? Dites-moi votre MAC!"
2. Je réponds avec une fausse MAC address à la place de B (ARP spoofing)
3. A reçoit la réponse et mémorise: "Cette IP -> Cette MAC"
4. A m'envoie le paquet.

Raw Sockets: ✅️
C'est un outil qui permet de construire moi même mes paquets.

Structure ARP: ✅️
Comment est construit un paquet ARP
- Je crée un paquet ARP
- Je le mets dans un Ethernet Frame (wrapper)
- Je l'envoie à A

Network Byte Order (htons, ntohl): ✅️
Le réseau parle en "big endian"
uint16_t port = htons(8080);  // htons convertit 8080 en big endian

Ethernet Frame: ✅️
C'est le "wrapper" autour du paquet ARP (header Ethernet)
1. Créer la structure Ethernet Frame
2. La remplir avec les bonnes valeurs
3. Y mettre le paquet ARP dedans
4. Envoyer le tout

Broadcast: ✅️
Comment envoyer un message à TOUT LE RÉSEAU (pas juste à une machine)
